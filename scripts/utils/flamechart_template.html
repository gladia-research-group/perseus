__GATE__
Self time is exclusive of children, so a subtree's frames sum to its width. Parent / unattributed is self time on container scopes — measured to be overwhelmingly the profiler's own per-scope cudaDeviceSynchronize, not un-instrumented work. Colour encodes op family; every frame is also labelled and tooltipped, so identity is never colour-alone. This is a flame CHART, not a flamegraph: x is real elapsed time from [proftrace], one record per scope instance, so every frame sits where it actually ran and a gap is the parent genuinely working rather than a packing artifact. Nothing here depends on an ordering heuristic — verified by checking that every nested frame falls inside a parent's interval. The timestamps bracket a device sync, which is what makes them measure GPU work rather than host enqueue, and also what inflates the total.

The chart above is rendered server-side, so it is readable with scripting disabled or broken; zoom, search and tooltips are enhancements layered on top.
