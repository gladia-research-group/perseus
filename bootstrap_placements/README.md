# Bootstrap plans behind the paper

Every directory holds one plan per transformer block (`block_N_placement.json`) and a
`PLAN_CMD.txt` with the exact recipe (graph, planner flags, error model) that
regenerates it. All plans are for GPT-2 decode, 12 blocks + LM head, on the captured graphs
under `graphs/`. `tests/test_paper_plans.py` re-plans each directory from its graph and
checks the result is identical.

| directory | paper row | planned | executed / token |
|---|---|---|---|
| `gpt2_decode_n32` | Table 1, Perseus 32-bit (main row) | 418 | 552 |
| `gpt2_decode_n64` | Table 1, Perseus 64-bit | 373 | 470 |
| `gpt2_decode_n32_dense` | Table 6, Perseus 32-bit, dense only | 481 | 643 |
| `gpt2_decode_n64_dense` | Table 6, Perseus 64-bit, dense only | 411 | 517 |
| `baselines/dacapo` | Table 1, DaCapo (rescued) | 577 | 711 |
| `baselines/orion` | Table 1, Orion (upstream tool on our graph, rescued) | 668 | 802 |
| `baselines/fhelipe` | Table 1, Fhelipe (era contract, rescued) | 1140 | 1274 |
| `baselines/fhelipe_dense` | Table 6, Fhelipe dense only | 2828 | 2990 |
| `ablations/cf_fixed_{7,8,9,10}` | Table 4, one fixed correction factor | 418–442 | see paper |
| `ablations/kappa_{1,...,128}` | Table 5, margin κ | 418 each | 552 |

Notes.
* `planned` counts placed refreshes + hint-triggered + deliberate bootstraps, which is what the
  paper reports; the runtime executes the same plan on the LM head as well, hence the larger
  per-token count.
* The 32-bit arms are priced with the measured accuracy table; the 64-bit arms with the
  analytic error model, which is how the paper planned them (`PLAN_ACC_CHAIN=`).
* The two 64-bit arms are captured and planned with automatic sparse routing on
  (`SPARSE_AUTO=2`, which needs `CORRECTION_FACTOR=7` on that chain), which is the shipped
  configuration.
* `baselines/orion` is the output of the released Orion placer driven over our graph and
  repaired by the rescue pass; it cannot be regenerated by `perseus-plan` and is shipped as an
  artifact.

Regenerate the main plan:

```bash
GRAPH_DIR=graphs/gpt2_decode_n32 OUT_NAME=gpt2_decode_n32 \
BTS_LEVEL=36 SRC_LEVEL=36 CACHE_READ_LEVEL=36 PLAN_LEVEL_UNIT=2 PLAN_CF_MAX=20 \
PLAN_NO_PRESCALE=1 PLAN_SPARSE_SLOTS=512,1 PLAN_SPARSE_BTS_OUT=1:26,512:36 PLAN_ACC_CHAIN=n32 \
MAX_LEVEL=50 PLAN_HARD_ENV_CAP=0 PLAN_MAG_SAFETY=2 bash scripts/utils/run_bootstrap_all_blocks.sh
```
