\begin{minipage}{\linewidth}\fontsize{11.5}{14.5}\selectfont
Encrypted GPT-2 small (all 12 blocks and the encrypted argmax) on 16 consecutive tokens of a
fixed text, 128-bit security. \textit{Bootstraps per token}: \textit{planned}
counts those the system's plan places, \textit{executed} all that run, including the ones the
model itself performs regardless of the plan. \textit{No plan}: bootstrap whenever a value runs
out of levels. \textit{s / token}: average time per token after the first, with its 95\%
interval. \textit{KL}: median divergence between the encrypted and the plaintext next-token
distributions; \textit{top-1}: how often the encrypted top token equals the plaintext one.
DaCapo and Orion place bootstraps as their released tools output them; all systems run on the
same runtime with the same bootstrap types and a budget of 48 levels.
$^{\star}$Our reimplementation, with the redundant-bootstrap removal its paper describes; the
released tool cannot plan these models. $^{\dagger}$Fails our accuracy check at one position
(reference token ranked 9th; the limit is 8).
\end{minipage}
